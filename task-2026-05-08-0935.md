## Technical Notes
- JSARToolKit5 fires `window.dispatchEvent(new Event('ARController-loaded'))` when library loads
- `ARController.getUserMediaThreeScene()` handles camera + Three.js setup automatically
- When marker detected: `arScene.process()` updates marker transform, `arScene.renderOn(renderer)` draws
- FBXLoader dynamically imported to avoid bundling Three.js in main bundle
