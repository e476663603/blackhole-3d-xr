## 15:02 - v9 部署：版本号可见性问题（defineConstants bug + 修复）

### 问题
- 用户需要能在浏览器里看到版本号（确认加载的是最新构建）
- Taro `defineConstants: { VERSION: ... }` 在 H5 模式下 **没有注入到编译**
- `declare const VERSION` 编译成 `undefined`
- HTML 注入 `window.__BUILD_VERSION__` 脚本也因 encode 问题导致语法错误

### 根本原因
Taro H5 编译时 defineConstants 配置不生效 — WebXR AR 页面的版本号机制完全失效。

### 解决方案
直接在 `src/index.html` 的 `<title>` 硬编码版本号：
```html
<title>blackhole-3d-xr v8.1452</title>
```
浏览器标签页打开就可见，无需 JS 加载。

### 清理工作
- 删除了 `config/index.ts` 中的 `defineConstants: { VERSION }`
- 删除了 `src/index.html` 中的 `window.__BUILD_VERSION__` script 注入
- 删除了 `src/pages/viewer/index.tsx` 中的 `declare const VERSION`
- 删除了所有临时 patch 文件
